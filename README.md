# DevOps Git Project

## Overview

This project demonstrates Git and GitHub best practices
for managing a DevOps project.

## Objectives

- Use Git for version control
- Create and manage branches
- Follow feature branch workflow
- Use Pull Requests
- Maintain project documentation
- Use .gitignore
- Create Git tags and releases

## Technologies

- Git
- GitHub
- Markdown

## Branching Strategy

### main
Production-ready code.

### dev
Development and integration branch.

### feature/*
Used for individual features or tasks.

## Workflow

1. Create a feature branch.
2. Make changes.
3. Commit changes.
4. Push the feature branch.
5. Create a Pull Request.
6. Merge into dev.
7. Test the dev branch.
8. Merge dev into main.
9. Create a version tag.
